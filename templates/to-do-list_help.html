🚀 快速开始

新用户注册

  1. 首次访问时，系统会要求您创建用户ID
  2. 输入至少8位字母或数字（如：sofia2025）
  3. 点击"注册并登录"
  4. 系统会自动创建一个使用说明任务，帮助您快速了解功能

添加第一个任务

  1. 点击页面顶部的"添加任务"按钮
  2. 输入任务标题（必填），如："完成项目报告"
  3. 输入任务内容（可选，支持Markdown格式）
  4. 设置开始日期和时间（默认为当前时间）
  5. 选择重复模式（不重复/每日重复/自定义重复）
  6. 点击"添加任务"按钮
💡 新手提示：
  • 添加任务后，表单会自动折叠，让您专注于任务列表
  • 系统自动生成的使用说明任务默认置顶，建议先阅读
  • 点击标题栏可以折叠/展开头部内容，界面更简洁

完成任务

找到要完成的任务，勾选任务前的复选框即可标记为完成。已完成的任务会添加删除线效果。

👤 用户系统

用户ID

用户ID是您账号的唯一标识，用于登录和跨设备同步数据。

特点：

  • 由8-64位字母或数字组成（如：sofia2025）
  • 注册后不可更改
  • 用于登录验证
  • 支持跨设备数据同步

如何查看ID：

  1. 点击页面中的"切换用户"按钮
  2. 在对话框中可以看到您的完整用户ID
  3. 点击"复制ID"按钮快速复制

昵称系统

昵称是您的公开显示名称，用于分享任务时标识身份，方便他人识别。

特点：

  • 最多32个字符
  • 可以随时修改
  • 用于任务分享时的署名
  • 他人可通过昵称向您分享任务

如何设置昵称：

  1. 方式1（推荐）：双击页面底部的"昵称"标签，直接修改
  2. 方式2：长按昵称标签（手机端）
  3. 方式3：首次登录时，系统会弹窗提示设置

ID vs 昵称

用户ID（敏感信息） ✓ 唯一标识，不可更改 ✓ 用于登录和跨设备同步 ✓ 建议不要随意公开 ✓ 界面中默认隐藏，仅在需要时显示 昵称（公开信息） ✓ 显示名称，可随时修改 ✓ 用于分享时标识身份 ✓ 可以公开告诉他人 ✓ 界面中始终显示昵称而非ID
⚠️ 隐私保护建议：
  • 日常使用中，只需告诉他人您的昵称即可
  • 用户ID类似于密码，不要随意公开
  • 分享任务时，系统只发送昵称，不发送ID
  • 界面中默认显示昵称，保护您的隐私

✏️ 任务管理

添加任务

  1. 点击"添加任务"按钮展开编辑表单
  2. 输入任务标题（必填）
  3. 输入任务内容（可选，支持Markdown格式）
  4. 设置开始日期和时间（默认为当前时间）
  5. 选择重复模式：
    • 不重复：任务只执行一次
    • 每日重复：每天相同时间重复
    • 自定义重复：按小时数自定义间隔
  6. 点击"添加任务"按钮
💡 快捷操作：添加任务后，表单会自动折叠,帮助您快速聚焦任务列表。需要继续添加时，再次点击"添加任务"即可。

编辑任务

  1. 找到要编辑的任务，点击右侧的"编辑"按钮
  2. 任务卡片会展开为编辑模式（黄色高亮背景）
  3. 修改标题、内容、时间或重复设置
  4. 点击"确认"保存修改
  5. 点击"取消"放弃更改

快捷键：

  • Enter - 在标题输入框中按Enter确认编辑
  • Ctrl/Cmd + Enter - 在内容输入框中确认编辑
  • Esc - 取消编辑
⚠️ 注意：如果将任务标题清空后保存，系统会提示删除该任务。

完成任务

勾选任务前的复选框即可标记为完成。已完成的任务会显示删除线效果。

置顶任务

对于重要或紧急的任务，可以将其置顶到列表最前面：

  1. 找到要置顶的任务
  2. 勾选任务日期后面的"置顶"复选框
  3. 任务立即跳到列表最前面，并显示黄色背景标识

置顶任务特点：

  • 黄色渐变背景 + 左侧黄色竖线标识
  • 始终排在非置顶任务前面
  • 支持同时置顶多个任务
  • 置顶状态会同步到服务器

删除任务

  1. 点击任务右侧的"删除"按钮
  2. 系统会弹出确认对话框
  3. 确认后，任务将被永久删除（无法恢复）

任务排序规则

系统会自动按以下优先级排序任务：

  1. 置顶任务优先：所有置顶任务排在最前面
  2. 未来任务优先：开始时间在未来的任务排在前面
  3. 时间临近优先：未来任务按时间从近到远排序
  4. 过去任务倒序：已过期任务按时间从晚到早排序
  5. 更新时间辅助：时间相同时，按最后更新时间排序

🔄 重复任务详解

不重复

任务只执行一次，完成后不会再次出现。适合一次性任务。

每日重复

任务每天在相同时间重复出现。完成当天任务后，第二天会自动生成新的待完成任务。

示例：每天早上8:00喝水 → 今天8:00完成后，明天8:00再次出现

自定义重复

可以按小时数设置重复间隔，提供三种预设选项：

  • 每周重复 (168小时)：每周在相同时间重复
  • 每月重复 (720小时)：每月（按30天计算）在相同时间重复
  • 自定义间隔：输入任意小时数（1-8760），如每2小时、每72小时等
💡 提示：系统会自动计算并显示"每周X次"和"每月X次"，帮助你了解任务频率。

重复任务的行为规则

  • 未完成任务：保持在当前周期，不会自动更新到下一周期
  • 已完成任务：下一周期到来时，自动重置为待完成状态
  • 时间显示：总是显示当前周期的开始时间

使用场景

每日重复

早起打卡、每日喝水、晨间运动

每周重复

周会、周报、垃圾清理

每月重复

月报、账单支付、体检

自定义间隔

每2小时休息、每4小时喝水

🔗 任务分享功能

什么是任务分享？

任务分享功能允许你将任务快速发送给其他用户，适合任务委派、协作提醒等场景。支持单用户分享、多用户分享和广播分享。

基础分享流程

  1. 找到需要分享的任务，点击右侧的"分享"按钮（绿色）
  2. 在弹出的对话框中，可以看到您的昵称
  3. 选择分享方式：署名分享（默认）或匿名分享
  4. 输入对方的昵称（推荐）或用户ID
  5. 点击"确认分享"按钮
  6. 系统提示分享成功后，对方即可在自己的账号中看到该任务

署名/匿名分享（v1.8.2新增）

分享任务时，可以选择署名分享或匿名分享，让对方知道或隐藏任务来源：

署名分享（默认推荐）

  • 对方看到：[来自XXX分享] 任务标题
  • 优点：对方知道任务来源，有问题可以找你确认，体现礼貌和责任感
  • 隐私保护：只显示您的昵称，不显示用户ID
  • 适用场景：正常工作协作、任务委派、会议提醒

匿名分享

  • 对方看到：任务标题（无前缀）
  • 优点：完全隐藏身份，避免尴尬或冲突
  • 隐私保护：不发送任何个人信息
  • 适用场景：敏感建议、匿名反馈、不想暴露身份
对比示例： 原始任务：完成项目报告 【署名分享】 → 对方看到：[来自张三分享] 完成项目报告 → 对方知道任务来自张三 【匿名分享】 → 对方看到：完成项目报告 → 对方不知道是谁分享的

多用户分享（最多3个）

一次性分享给多个用户，操作更高效：

  1. 点击任务的"分享"按钮
  2. 在输入框中输入昵称或ID，会显示匹配的用户列表
  3. 点击下拉列表中的用户即可添加（最多3个）
  4. 已选择的用户会以标签形式显示在输入框上方
  5. 点击标签上的"×"可移除该用户
  6. 点击"确认分享"，任务会同时发送给所有选中的用户

广播分享（彩蛋功能）

需要通知所有人时，可以使用特殊关键词进行广播分享：

  1. 点击任务的"分享"按钮
  2. 在输入框中输入广播关键词（如：@all、@所有人）
  3. 点击"确认分享"
  4. 系统会弹出确认对话框，显示将分享给多少个用户
  5. 确认后，任务会发送给除自己外的所有注册用户
  6. 显示实时进度条，展示分享进度
⚠️ 广播分享注意事项：
  • 支持的关键词：@all、@All、@ALL、@所有人、@全部、@所有、@全部用户、@所有用户
  • 会分享给除自己外的所有注册用户
  • 系统会要求二次确认，避免误操作
  • 请谨慎使用，避免频繁打扰其他用户
  • 适用场景：重要通知、紧急任务、全员活动

分享功能特点

  • 支持昵称：可以使用对方的昵称或用户ID，昵称更便于记忆
  • 署名/匿名：自由选择是否显示分享者身份
  • 多用户支持：一次最多选择3个用户（广播不受限制）
  • 智能搜索：输入时实时搜索匹配的昵称和ID
  • 标签显示：已选择的用户以可移除标签形式显示
  • 完整复制：任务的标题、内容、时间、重复设置都会完整复制
  • 独立副本：分享后的任务是独立的副本，双方互不影响
  • 状态重置：分享的任务默认为"未完成"状态
  • 新建ID：系统会为分享的任务生成新的唯一ID
  • 插入顶部：分享的任务会出现在对方任务列表的顶部
💡 推荐做法：
  • 使用对方的昵称进行分享，更容易记忆
  • 分享前先设置好您的昵称（双击底部"昵称"标签快速修改）
  • 正常协作时选择署名分享，让对方知道任务来源
  • 敏感建议时选择匿名分享，保护隐私
  • 广播分享前务必确认任务内容，避免给他人造成困扰

使用场景

任务委派

将需要他人完成的任务分享给对方，明确责任和时间

会议提醒

将会议任务分享给所有参会人员

协作任务

将需要多人协作的任务分享给团队成员

学习打卡

将学习计划分享给学习伙伴，互相监督

👥 任务协作功能

什么是任务协作?

任务协作功能允许多个用户共同管理同一个任务,所有协作者对任务的修改会实时同步给其他人。与任务分享不同,协作任务是共享的单一任务,而非创建多个副本。

协作 vs 分享的区别

任务分享(📤) ✓ 创建任务副本发送给对方 ✓ 双方任务独立,互不影响 ✓ 适合任务委派、提醒通知 ✓ 一次性操作 任务协作(👥) ✓ 多人共享同一个任务 ✓ 任何人的修改都会同步 ✓ 适合团队项目、共同目标 ✓ 持续协作管理

创建协作任务

有两种方式创建协作任务:

方式1: 新建时直接创建

  1. 点击任务右侧的"分享"按钮
  2. 在弹出菜单中选择"任务协作"(👥图标)
  3. 进入协作管理页面,点击"创建新协作任务"
  4. 填写任务标题、内容、时间等信息
  5. 添加协作者(输入昵称或ID搜索)
  6. 点击"创建协作任务"完成

方式2: 转换已有任务

  1. 点击任务右侧的"分享"按钮
  2. 选择"任务协作"进入协作管理页面
  3. 点击"转换为协作任务"标签页
  4. 在列表中找到要转换的任务
  5. 点击"转换"按钮
  6. 添加协作者
  7. 确认转换
💡 转换提示:
  • 转换后原任务将变为协作任务,不可逆
  • 所有协作者都能看到并修改该任务
  • 任务标题旁会显示👥标识

管理协作者

协作任务创建后,可以随时添加或移除协作者:

添加协作者

  1. 在主页找到协作任务(标题旁有👥标识)
  2. 点击👥标识打开管理界面
  3. 或者通过分享按钮 → 任务协作进入管理页面
  4. 找到该协作任务,点击"管理"按钮
  5. 在弹出对话框中输入新协作者的昵称或ID
  6. 点击"添加协作者"

移除协作者

  1. 打开协作者管理对话框(同上)
  2. 在协作者列表中找到要移除的用户
  3. 点击该用户右侧的"移除"按钮
  4. 确认移除操作
⚠️ 权限说明:
  • 所有协作者拥有平等权限,都能修改任务、添加/移除协作者
  • 任务创建者可以删除整个协作任务
  • 协作者可以选择退出协作(移除自己)
  • 至少需要保留一个协作者

协作任务的特点

  • 实时同步:任何协作者的修改都会立即同步给其他人
  • 👥标识:协作任务标题旁会显示👥图标,点击可查看协作者
  • 共享附件:协作者可以共同管理任务附件
  • 完成状态:任何协作者都可以标记任务完成/未完成
  • 历史追溯:系统记录谁创建了该协作任务

常见问题

Q: 协作任务和分享任务有什么区别?

A: 分享任务会创建副本发送给对方,双方任务独立互不影响;而协作任务是多人共享同一个任务,任何人的修改都会同步给所有协作者。

Q: 协作任务可以转回普通任务吗?

A: 目前不支持将协作任务转回普通任务。如需个人管理,建议使用"任务分享"功能复制一份给自己。

Q: 如何退出某个协作任务?

A: 打开协作者管理对话框,在协作者列表中找到自己,点击"移除"即可退出。退出后将不再收到该任务的同步更新。

Q: 协作任务的附件所有人都能看到吗?

A: 是的,协作任务的附件对所有协作者可见,所有人都可以上传、下载和删除附件。

Q: 可以限制某些协作者的权限吗?

A: 目前所有协作者拥有平等权限。如需权限控制,建议使用"任务分享"功能单向发送任务副本。

📎 附件管理（v2.1.8更新）

什么是附件功能？

附件功能允许您为任务添加图片、文档、音视频等文件，让任务信息更完整、更直观。支持50多种文件格式，单文件最大233MB。

基础操作流程

  1. 找到需要添加附件的任务，点击右侧的"附件"按钮
  2. 进入附件管理页面，点击"上传文件"按钮
  3. 选择要上传的文件（支持拖拽上传）
  4. 上传成功后，附件会显示在列表中
  5. 点击附件名称可下载，点击"删除"可移除

支持的文件类型

📷 图片

jpg, png, gif, webp, svg, bmp

📄 文档

pdf, doc, docx, xls, xlsx, ppt, txt, md

🗜️ 压缩包

zip, rar, 7z, tar, gz

🎬 音视频

mp3, mp4, avi, mov, wav

💻 代码

py, js, html, css, json, xml

📊 其他

共支持50+种文件格式

智能去重技术（v2.1.0新增）

系统采用引用式附件架构，自动识别并复用相同文件，大幅节省存储空间：

  • 自动去重：上传相同文件时，系统自动检测并复用，不重复存储
  • 节省空间：相同文件只存储一份，可节省50%-80%空间
  • 快速分享：分享任务时，附件创建引用链接而非复制文件，速度提升100倍
  • 配额优化：分享来的附件不占用您的配额，只有您上传的文件才计入
智能去重示例： 场景1：重复上传 → 您上传了 report.pdf (5MB) → 再次上传同一文件 → 系统提示"上传成功（复用已存在文件）" → 实际只占用5MB，而非10MB 场景2：任务分享 → 您分享了带10个附件的任务给同事 → 传统方式：复制10个文件，耗时30秒 → 新方式：创建10个引用，耗时0.3秒（100倍提升） → 同事收到的附件不占用TA的配额

存储配额管理

  • 个人配额：每个用户5GB存储空间
  • 单文件限制：单个文件最大233MB（斐波那契数）
  • 任务附件数：单个任务最多55个附件
  • 配额显示：附件页面实时显示已用/总容量
  • 智能计算：只计算您上传的文件，分享来的不占用配额
💡 查看配额：
  • 进入任意任务的附件管理页面
  • 页面顶部会显示"存储空间：X.XMB / 5GB"
  • 百分比条形图直观展示使用情况

附件分享机制

当您分享包含附件的任务时，附件处理方式取决于系统版本：

新系统（v2.1.0引用式）

  • 创建引用：不复制文件，只创建引用链接
  • 极速分享：10个附件约0.3秒完成
  • 不占配额：接收者不消耗存储空间
  • 共享存储：多人共享同一文件，节省服务器资源

旧系统（兼容模式）

  • 完整复制：复制文件副本给接收者
  • 独立存储：接收者独立占用配额
  • 向后兼容：旧附件继续正常使用
  • 标记识别：系统自动标记为"旧系统附件"
⚠️ 附件使用注意事项：
  • 不支持的文件类型会被拒绝上传
  • 超过233MB的文件无法上传
  • 配额不足时需要先删除旧附件
  • 删除附件后，如果文件无人使用，24小时后自动清理
  • 建议只上传任务必需的文件，避免浪费空间

图片预览功能

图片类附件（jpg、png、gif等）支持在线预览：

  • 点击图片附件名称，会在新标签页打开预览
  • 支持大图查看，方便查看截图、设计稿等
  • 预览不消耗下载次数

🔍 搜索与筛选

快捷筛选按钮（v2.3.0新增）

搜索框旁边提供了两个快捷按钮，方便快速切换筛选状态：

H/A 按钮（显示/隐藏已完成）

  • H：隐藏已完成任务（Hide），默认状态
  • A：显示全部任务（All），包括已完成
  • 点击按钮在两种状态间切换

循环筛选按钮（全部/进行/完成）

  • 点击按钮在三种状态间循环切换：全部 → 进行 → 完成 → 全部
  • 全部：显示所有任务
  • 进行：只显示进行中（未完成）的任务
  • 完成：只显示已完成的任务

传统筛选按钮

  • 全部：显示所有任务（默认隐藏已完成，可点击"显示已完成"切换）
  • 待完成：只显示未完成的任务
  • 已完成：只显示已完成的任务，可批量清除

搜索功能

在搜索框中输入关键词，系统会实时搜索任务的标题和内容，支持多个关键词（用空格分隔）。

搜索示例： 输入"工作 会议" → 显示同时包含"工作"和"会议"的任务

清除已完成

在"已完成"筛选下，点击"清除已完成"按钮，可以批量删除所有已完成的任务。系统会要求确认，避免误操作。

💾 数据管理

自动保存

系统会自动保存您的所有操作：

  • 本地缓存：数据保存在浏览器的IndexedDB中
  • 服务器同步：400ms延迟后自动同步到服务器
  • 跨设备同步：使用同一用户ID登录，数据自动同步

导出备份

  1. 点击页面中的"导出"按钮
  2. 系统会下载一个JSON格式的备份文件
  3. 文件名格式：todos-backup-YYYY-MM-DD.json
  4. 建议定期导出备份，保障数据安全

导入恢复

  1. 点击"导入"按钮
  2. 选择之前导出的JSON备份文件
  3. 系统会智能合并数据：
    • 相同ID的任务，保留更新时间较新的版本
    • 新任务直接添加到列表中

切换用户

  1. 点击"切换用户"按钮
  2. 查看当前用户信息（昵称和ID）
  3. 输入新的用户ID登录或注册
  4. 系统会加载新用户的数据
⚠️ 数据安全建议：
  • 定期导出备份，养成备份习惯
  • 不要在公共设备上保存重要数据
  • 妥善保管用户ID，避免泄露
  • 切换用户前，确保当前数据已同步

常见问题

Q: 忘记用户ID怎么办？

A: 如果您记得昵称，可以询问经常与您协作的朋友。如果完全忘记，只能重新注册新用户ID。

Q: 数据会丢失吗？

A: 数据同时保存在浏览器本地和服务器，双重保障。建议定期导出备份，更加安全。

Q: 可以撤销分享吗？

A: 分享后无法撤回，但对方可以自行删除任务。分享前请仔细确认。

Q: 署名分享会暴露我的用户ID吗？

A: 不会。署名分享只显示您的昵称，不会发送用户ID，保护您的隐私。

Q: 如何彻底删除账号？

A: 目前暂不支持自助删除账号。如需删除，请联系管理员。
